# Larp Upgrader

Расширение для Chrome, чтобы поразвлечься с upgrader.vip прямо у себя в браузере. Ничего никуда не отправляется — всё крутится локально у тебя на компе.

## Что оно делает

- **Свой баланс** — ставишь любую сумму, она показывается прямо на сайте в шапке
- **Каталог скинов** — штук 50+ CS2 скинов, с поиском и фильтром по редкости
- **Локальные апгрейды** — выбираешь скины, крутишь рулетку, смотришь спиннер-анимацию
- **История** — журнал попыток: что проиграл, что выиграл
- Плавающая панелька в углу страницы, всё делается оттуда

## Как поставить

1. Открываешь `chrome://extensions/`
2. Включаешь «Режим разработчика» в углу
3. Жмёшь «Загрузить распакованное расширение» и выбираешь эту папку
4. Заходишь на upgrader.vip

## Как юзать

- **Попап расширения** — поставить баланс (Set или кнопки 1K / 10K / 100K / 1M, Reset обнуляет)
- **Панель на сайте** (справа сверху):
  - Set Balance — свой баланс
  - Open Catalog — каталог скинов
  - Start Upgrade — апгрейд: выбираешь скин, цель, шанс, жмёшь UPGRADE!
  - History — что вообще было
  - чекбокс «Intercept site upgrade API» — по желанию, подменяет ответ кнопки апгрейда сайта. Осторожно, может сломать вёрстку сайта. Включай на свой страх.

## Иконка

Запустить `generate-icon.html`, скачается `icon.png` (в git она не хранится, поэтому положи в папку сам).

## Мелочи

- Механизм простой: подменяет ответы API (`/api/user`, `/api/balance` и т.п.), прячет заглушки «пополните баланс», баланс рисуется прямо в DOM
- Всё в localStorage браузера — закрыл вкладку, скины на месте
- Работает только у тебя, для остальных сайт как был

## Предупреждение

Ясно дело, для сайта это типа «читерство». Для остальных пользователей и сервера ничего не меняется. Поставь репозиторий в приватный, если не хочешь светить это в паблик.
