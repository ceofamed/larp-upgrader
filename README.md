# Upgrader Custom - Chrome Extension

Локальное расширение для кастомизации сайта upgrader.vip

## Возможности

- **Свой баланс** - устанавливайте любой баланс (показывается прямо на сайте в шапке/профиле)
- **Каталог скинов** - 50+ CS2 скинов: поиск, фильтры по редкости, добавить выбранные/все/случайный
- **Локальный апгрейд** - спиннер-анимация, шанс победы, win/lose результаты
- **История апгрейдов** - журнал всех результатов в панели
- **Ничего не уходит на сервер** - все данные хранятся в localStorage
- **Плавающая панель UC** - баланс, быстрые кнопки (1K-1M-MAX), каталог, апгрейд, история

## Установка

1. Откройте `chrome://extensions/`
2. Включите "Режим разработчика" (Developer mode) в правом верхнем углу
3. Нажмите "Загрузить распакованное расширение" (Load unpacked)
4. Выберите папку `upgrader-extension`
5. Откройте https://upgrader.vip/ru

## Генерация иконки

Перед установкой сгенерируйте иконку:
1. Откройте файл `generate-icon.html` в браузере
2. Иконка автоматически скачается как `icon.png`
3. Поместите `icon.png` в папку `upgrader-extension`

## Использование

### Попап расширения
- Показывает текущий баланс и количество скинов в инвентаре
- Установка баланса (кнопка Set / быстрые 1K-10K-100K-1M)
- Reset обнуляет баланс
- Синхронизируется с сайтом через сообщения (content script)

### Плавающая панель (правый верхний угол сайта)
- **Set Balance** - ввести любой баланс, обновляется на сайте
- Быстрые кнопки: 1K, 10K, 100K, 1M, MAX
- **Open Catalog** - каталог скинов (поиск + фильтры редкости)
- **Start Upgrade** - открывает локальный апгрейд (выбор скина, цель, шанс, спиннер)
- **History** - журнал попыток апгрейда (WIN/LOSE)
- Чекбокс "Intercept site upgrade API" - опциональный перехват кнопки апгрейда сайта

### Апгрейд
- Нажмите "Start Upgrade" в панели
- Выберите скин для апгрейда и целевой скин
- Настройте шанс (слайдер)
- Нажмите "UPGRADE!" - спиннер-анимация 4 секунды
  - WIN: оба скина исчезают, добавляется целевой
  - LOSE: оба скина исчезают

### Механизм перехвата
- Ответы `/api/user`, `/api/auth`, `/api/balance`, `/api/wallet`, `/api/me` подменяются (баланс = ваш)
- Скрываются заглушки "пополните баланс" (`up-advertising-table-unlock-stub` и пр.)
- Опционально: перехват POST `/api/game/upgrade` для локального ответа (ОСТОРОЖНО, может сломать UI сайта - включайте на свой риск)

## Примечание

Это расширение работает **полностью локально**. Все изменения видны только вам в вашем браузере. Сервер сайта не получает никакой информации.
